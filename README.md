# Real Estate House Price Prediction

## 🎯 Objective
The objective of this project is to understand, implement, and evaluate supervised learning algorithms, with a focus on regression techniques and model performance analysis[cite: 1].

The project aims to explore:
* Linear Regression and its variants[cite: 1]
* Gradient Descent optimization techniques[cite: 1]
* Model performance evaluation[cite: 1]
* Bias–Variance Trade-Off[cite: 1]
* Overfitting and Underfitting[cite: 1]
* Model behavior and diagnostic analysis[cite: 1]

## 📂 Dataset Overview
The project utilizes the `RealEstate_HousePrice_Dataset_4200.csv` dataset, which contains 4,200 property records and 12 columns[cite: 1]. 

* **Independent Variables (Features):** House Area (sq.ft), Number of Bedrooms, Number of Bathrooms, Location Score, and Age of Property[cite: 1].
* **Dependent Variable (Target):** House Price in INR (`house_price_inr`)[cite: 1].

## 🛠️ Libraries Used
The analysis and modeling are performed using Python and the following libraries:
* **Data Manipulation:** `pandas`, `numpy`[cite: 1]
* **Visualization:** `matplotlib.pyplot`, `seaborn`[cite: 1]
* **Machine Learning:** `scikit-learn` (for Linear Regression, Train-Test Split, and Metrics)[cite: 1]

## 🚀 Project Structure
* **Part-A (Theory):** Covers foundational machine learning concepts including Supervised Learning, Regression vs. Classification, the assumptions of Simple Linear Regression, the Bias-Variance Trade-Off, and Overfitting vs. Underfitting[cite: 1].
* **Part-B (Data Preparation & EDA):** Includes loading the dataset, checking data shape and null values, defining features/targets, and visualizing relationships using scatter pair plots[cite: 1].
* **Part-C (Modeling):** Involves splitting the data into training (80%) and testing (20%) sets, followed by the implementation of a Simple Linear Regression model to predict house prices based strictly on the house area[cite: 1].
